# logdaurna

Auditor de Log de Urna — ferramenta independente de análise de logs de urna eletrônica.
Processamento 100% local no navegador, sem envio de dados.

## Uso
Abra index.html no navegador e solte o arquivo .zip, .jez ou logd.dat.

## Aviso
Não é produto da Justiça Eleitoral. Os resultados oficiais são os do Boletim de Urna.
